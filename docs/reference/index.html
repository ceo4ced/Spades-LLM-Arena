Overview

Spades LLM Arena (what it is)

Shipped

Bots-vs-bots Spades; LLMs in 4 seats; persistent SpacetimeDB leaderboard.

Source: README.md

Four seats, four bots, real Spades. Each seat is configured to a model (random, heuristic, or any LLM via OpenRouter / Anthropic / OpenAI / Gemini). The engine runs the game; agents return bids and plays in response to observations; results are persisted to SpacetimeDB Maincloud where any client can subscribe to a live leaderboard and head-to-head matchups.

The benchmark exists because off-the-shelf LLM evals (MMLU, HumanEval, etc.) do not measure multi-step decision-making under hidden information with partner coordination. Spades does. The same harness also serves as a reference implementation for runtime constraint enforcement (see the SARC mapping in Research/NOTES.md).

// Top-level building blocks. Each is documented in its own page.
interface SpadesArena {
    GameEngine    engine;       // pure-TS rules, scoring, state machine
    Agent[4]      seats;        // one Agent per seat
    SpacetimeDB   store;        // game / hand / decision / model tables
    ReactUI       ui;           // GameSetup, GameBoard, Dashboard, ...
    Orchestrator  stream;       // headless Playwright + FFmpeg → YouTube

    void          startMatch(GameConfig cfg);
    Leaderboard   liveLeaderboard();
}
// Lifecycle of one match, end-to-end.
on user clicks "Start Match":
    config = GameSetup.read()                        // variant, target, seats, policy, seed?
    engine = new GameEngine(config)                  // assigns rngSeed if none provided
    agents = [buildAgent(p) for p in config.players] // RandomAgent / LLMAgent / …
    until engine.phase == game_over:
        seat       = engine.currentTurn
        obs        = engine.getObservation(seat)
        action     = await agents[seat].decide(obs)
        engine.apply(action)                         // validates + may log cheat events
    saveResult(engine.state) → localStorage
    recordCompleteGame(...) → SpacetimeDB (best-effort)

Architecture map

Shipped

Where each subsystem lives and how data flows between them.

Source: README.md·src/·spacetime/

Six subsystems: engine, agents, hooks, components, spacetime client, spacetime module. Plus two adjacent pieces: a Rust encoding crate that the module uses to pack hands/bids/tricks compactly, and the streaming orchestrator that drives a headless browser so unattended games can broadcast to YouTube.

Data flows downhill: UI configures, hooks drive the loop, engine produces state, agents consume observations and emit actions, and the spacetime client batches results to the module. The module is the only piece running in the cloud; everything else lives in the browser or the Node orchestrator process.

package src.engine;     // pure rules, no IO

End-to-end data flow

Shipped

One bid/play decision, traced through every layer.

Source: src/hooks/useGame.ts·src/engine/game.ts·src/agents/base.ts

Take a single decision (Bot 2 plays the 9♠) and follow it through the code. This is the most useful mental model for the whole project: the loop is tight, the data is small, and almost every other doc page below is some specialization of one of these steps.

// Each tick of the game loop:
class Tick {
    Observation buildObservation(int seat);                         // engine
    Action      askAgent(Observation obs);                          // agent
    String?     apply(int seat, Action a);                          // engine; null = ok
    void        log(String message);                                // hook
    void        recordIfGameOver();                                 // hook → spacetime-client
}
// One iteration of useGame.runLoop(), the heart of the system.
state = engine.state
if state.phase == game_over: recordResults(); return
seat  = state.currentTurn
agent = agents[seat]
if agent is null: setIsHumanTurn(true); return        // wait for human input

await sleep(speed)                                    // UI pacing
obs  = engine.getObservation(seat)                    // legal_plays computed here
if state.phase == bidding:
    action = await agent.bid(obs)                     // {action:"bid", value, reasoning}
    err    = engine.processBid(seat, action)
else:
    action = await agent.play(obs)                    // {action:"play", card, reasoning}
    err    = engine.processPlay(seat, action)         // may log a CheatEvent

if err: log(err); engine.applyFallback(seat)          // RandomAgent picks a legal action
setGameState({...engine.state})                       // triggers UI re-render
if engine.isTrickComplete(): engine.resolveTrick()    // also scoreHand at hand boundary
schedule next tick (runLoop)
Engine

GameEngine — the state machine

Shipped

Owns game state, advances turns, validates actions, applies cheat consequences.

Source: src/engine/game.ts

The single class that holds GameState and exposes every legal mutation. Construction deals 13 cards per seat, picks a dealer (real Spades cuts → seeded RNG), and waits for bidding. processBid / processPlay are the only mutators agents can drive; resolveTrick + scoreHand close the trick / hand boundaries. The constructor takes a CheatingPolicy and an rngSeed, both with sane defaults — pass them to reproduce a specific game or change house rules.

public class GameEngine {
    public GameState        state;
    public final String     variant;       // "standard" | "jokers"
    public final BigInt     rngSeed;       // persisted with each game
    public final CheatingPolicy policy;
    public List<CheatEvent> cheatEvents;
    public HandResult       lastHandResult;

    public GameEngine(int targetScore,
                      String variant,
                      Integer initialDealer,   // optional
                      CheatingPolicy policy,   // default STRICT
                      BigInt rngSeed);         // default generateRandomSeed()

    public void           dealHand();
    public Observation    getObservation(int seat);
    public String?        processBid(int seat, BidAction a);   // null = success
    public String?        processPlay(int seat, PlayAction a);
    public boolean        isTrickComplete();
    public void           resolveTrick();
    public void           scoreHand();
}
constructor(targetScore, variant, initialDealer?, policy?, rngSeed?):
    this.policy   = policy ?? STRICT_CHEATING_POLICY
    this.rngSeed  = rngSeed ?? generateRandomSeed()    // crypto-random 64-bit
    this.rng      = seededRng(this.rngSeed)            // splitmix64
    dealer        = initialDealer ?? floor(rng() * 4)
    initState(dealer); dealHand()

processPlay(seat, action):
    guard phase == playing and currentTurn == seat
    card  = parseCard(action.card)
    guard player.hand contains card
    legal = getLegalPlays(player.hand, ledSuit, spadesBroken,
                           forcedOpeningCard(), policy.spadesLeadPolicy)
    if card not in legal:
        if !policy.allowRenege or isForcedOpening: return "Illegal play"
        kind = (isLead ? IllegalLead : Renege)
        endedGame = recordAndApplyCheat({seat, kind, card})
        if endedGame: return null    // GameForfeit short-circuits
    apply: remove card from hand, append to currentTrick.plays
    if !ledSuit: set ledSuit = card.suit
    if card.isSpade: spadesBroken = true
    if !isTrickComplete(): currentTurn = (currentTurn + 1) % 4

scoreHand():
    if policy.minimumTeamBid > 0: flag any team whose bid is below floor
    apply calculateTeamScore for each team
    deduct pendingPenalties (from CheatConsequence.HandPenalty)
    if either team reached targetScore: phase = game_over
    else: advance dealer, increment handNumber, dealHand()

rules.ts — legal-play oracle

Shipped

getLegalPlays + determineTrickWinner. Pure functions, no state.

Source: src/engine/rules.ts

Two pure functions. getLegalPlays is the Pre-Action Gate (SARC mapping): it filters the hand down to the subset the player is allowed to commit, honoring follow-suit, spades-breaking, the universal opening-card rule, and the optional AlwaysAllowed lead policy. determineTrickWinner picks the winning seat once four cards have been played.

public final class Rules {
    public static List<Card> getLegalPlays(
        List<Card>       hand,
        Suit?            ledSuit,           // null when this seat leads
        boolean          spadesBroken,
        String?          forcedOpeningCardId, // "2C"/"3C" on trick 1
        SpadesLeadPolicy leadPolicy            // default MustBeBroken
    );
    public static int determineTrickWinner(List<TrickPlay> plays, Suit ledSuit);
}
getLegalPlays(hand, ledSuit, spadesBroken, forcedOpener, leadPolicy):
    if ledSuit is null:                            // we are leading
        if forcedOpener and hand contains it: return [forcedOpener]
        if leadPolicy == MustBeBroken and !spadesBroken and hand has non-spades:
            return hand.filter(c => not isTrump(c))
        return hand.copy()
    if ledSuit == Spades:
        suitCards = hand.filter(isTrump)           // jokers count as spades
    else:
        suitCards = hand.filter(c => c.suit == ledSuit)
    return suitCards.nonEmpty ? suitCards : hand.copy()

determineTrickWinner(plays, ledSuit):
    winner = plays[0]
    for each subsequent play p:
        if p.card is trump and winner.card is not: winner = p
        else if both trumps and value(p) > value(winner): winner = p
        else if neither trump and p.suit == winner.suit and value(p) > value(winner): winner = p
        else if neither trump and p.suit == ledSuit and winner.suit != ledSuit: winner = p
    return winner.seat

deck.ts — cards, shuffle, parse

Shipped

Builds the 52- or 54-card deck, Fisher-Yates shuffle (RNG-injected), parses card ids.

Source: src/engine/deck.ts

Card ids are short strings ("AS", "10H", "BigJoker"). createDeck returns 52 cards in standard, 52 in jokers (removes 2♣/2♦, adds Big/Little Jokers). shuffle is Fisher-Yates parameterized by an RNG function so the engine can supply a seeded source for reproducibility. getCardValue and parseCard are utilities.

public final class Deck {
    public static List<Card> createDeck(String variant);              // "standard" | "jokers"
    public static List<Card> shuffle(List<Card> deck, () => double rng);  // default Math.random
    public static int        getCardValue(Rank r, Suit s);
    public static Card?      parseCard(String id);
}
createDeck(variant):
    deck = []
    for suit in [S,H,D,C]:
        for rank in [A,K,Q,J,10..2]:
            if variant == "jokers" and (suit in {C,D}) and rank == "2": skip
            deck.push({suit, rank, id: rank+suit})
    if variant == "jokers":
        deck.push({suit:"J", rank:"Big",    id:"BigJoker"})
        deck.push({suit:"J", rank:"Little", id:"LittleJoker"})
    return deck

shuffle(deck, rng):
    a = deck.copy()
    for i from a.length-1 down to 1:
        j = floor(rng() * (i+1))
        swap a[i] and a[j]
    return a

scoring.ts — points, bags, nil

Shipped

calculateTeamScore: bid satisfaction, overtricks, bags, nil bonuses, bag penalty.

Source: src/engine/scoring.ts

A single pure function. Given a team's two players and the team's pre-hand state, returns the post-hand score and bag count. Honors nil bids (±100), team bid satisfaction (10× bid + 1 bag per overtrick), failure (−10× bid), and the standard bag penalty (−100 per 10 bags accumulated, with the bag counter wrapping).

public final class Scoring {
    public static TeamState calculateTeamScore(
        PlayerState player1,
        PlayerState player2,
        TeamState   current
    );
}
calculateTeamScore(p1, p2, current):
    score = current.score; bags = current.bags
    for each (bid, won) in [(p1.bid, p1.won), (p2.bid, p2.won)]:
        if bid == 0:                              // nil
            score += (won == 0 ? +100 : -100)
    teamBid = sum of non-nil bids
    teamWon = sum of tricks won by non-nil bidders
    if teamBid > 0:
        if teamWon >= teamBid:
            score += teamBid * 10
            over = teamWon - teamBid
            score += over; bags += over
        else:
            score -= teamBid * 10
    while bags >= 10:                             // bag penalty
        score -= 100; bags -= 10
    return {score, bags}

rng.ts — seeded reproducibility

Shipped

splitmix64 PRNG + crypto seed generator. Same seed → same deal.

Source: src/engine/rng.ts·src/engine/rng.test.ts

splitmix64 is a single-state 64-bit PRNG with good statistical quality. seededRng wraps it as a Math.random-compatible () => double function so existing call sites (Fisher-Yates, dealer pick) can switch without changing their math. generateRandomSeed uses Web Crypto when available and falls back to Math.random on legacy hosts (should never trigger in modern browsers / Node ≥ 19).

public final class Rng {
    public static () => double seededRng(BigInt seed);    // splitmix64
    public static BigInt       generateRandomSeed();      // u64-range
}
seededRng(seed):
    state = (seed & u64) or 1n             // avoid degenerate zero
    return () => {
        state = (state + 0x9E3779B97F4A7C15) & u64
        z = state
        z = ((z xor (z >> 30)) * 0xBF58476D1CE4E5B9) & u64
        z = ((z xor (z >> 27)) * 0x94D049BB133111EB) & u64
        z = z xor (z >> 31)
        return Number(z >> 11) / 2^53          // top 53 bits → [0, 1)
    }

generateRandomSeed():
    if crypto.getRandomValues exists:
        buf = new BigUint64Array(1)
        crypto.getRandomValues(buf)
        return buf[0]
    return (hi32 << 32) | lo32 from Math.random

CheatingPolicy + CheatEvent

Shipped

Per-game policy data + the audit-trail event type.

Source: src/engine/types.ts·src/engine/game.cheating.test.ts

CheatingPolicy is the input to runtime enforcement; CheatEvent is the output. The four presets in GameSetup (Strict, Permissive, Penalty, Forfeit) are concrete CheatingPolicy values. CheatEvent is the append-only trace produced by the engine — SARC's Post-Action Auditor in concrete form.

enum SpadesLeadPolicy     { MustBeBroken, AlwaysAllowed }
enum CheatConsequenceKind { LogOnly, HandPenalty, GameForfeit }
enum EngineCheatKind      { Renege, IllegalLead, BidBelowMinimum }

class CheatingPolicy {
    boolean             allowRenege;
    SpadesLeadPolicy    spadesLeadPolicy;
    int                 minimumTeamBid;     // 0 disables floor
    CheatConsequence    consequence;        // {kind, value}
}

class CheatEvent {
    int               handNumber;
    int               trickNumber;          // 0 for bid-time events
    int               seat;
    EngineCheatKind   kind;
    { String? card; int? bid; }  attempted;
    CheatConsequenceKind consequence;
    int               penaltyApplied;
    boolean           endedGame;
}
recordAndApplyCheat(base):
    consequence = policy.consequence
    penalty     = 0
    endedGame   = false
    switch consequence.kind:
        HandPenalty:
            team = (base.seat % 2 == 0 ? 1 : 2)
            pendingPenalties[team] += consequence.value
            penalty = consequence.value
        GameForfeit:
            offender = (base.seat % 2 == 0 ? 1 : 2); opp = 3 - offender
            scores[opp]      = targetScore
            scores[offender] = min(scores[offender], targetScore - 1)
            phase = game_over
            endedGame = true
        LogOnly: (no score effect)
    cheatEvents.push({...base, consequence: consequence.kind, penaltyApplied: penalty, endedGame})
    return endedGame

runner.ts — headless game driver

Shipped

Drives an engine + 4 agents to completion without React. Used by streaming.

Source: src/engine/runner.ts

A thin async loop that mirrors useGame.runLoop but with no UI. The streaming orchestrator and benchmark scripts use it to play games headlessly. It produces the same GameResult shape that the React loop produces, so downstream code (saveResult, recordCompleteGame) is identical.

public final class Runner {
    public static GameResult runGame(
        GameConfig cfg,
        Agent[]    agents,
        (String)   logSink             // optional progress callback
    );
}
runGame(cfg, agents, log):
    engine = new GameEngine(cfg.targetScore, cfg.variant, …, cfg.cheatingPolicy, cfg.rngSeed)
    while engine.phase != game_over:
        seat   = engine.currentTurn
        obs    = engine.getObservation(seat)
        action = await agents[seat].decide(obs)
        engine.apply(action)
        if engine.isTrickComplete(): engine.resolveTrick()
    return buildGameResult(engine)

Agent interface

Shipped

The 3-method contract every seat must implement.

Source: src/agents/base.ts

Three methods: bid, play, reset. bid and play are async because real agents call HTTP APIs; the engine awaits them per turn. reset is used when retrying mid-game (e.g., the OpenRouter rate-limit fallback cleared via reset()).

public interface Agent {
    String                  name();
    Future<BidAction>       bid(Observation o);
    Future<PlayAction>      play(Observation o);
    void                    reset();
}
// All agents follow the same shape:
class XxxAgent implements Agent:
    constructor(name, …provider-config):
        store config; store any sticky state (e.g., rate-limited flag)
    bid(obs):
        decision = computeDecision(obs)        // provider-specific
        return {action: "bid", value, reasoning}
    play(obs):
        decision = computeDecision(obs)
        return {action: "play", card, reasoning}
    reset():
        clear sticky state (rate-limited flag etc.)

RandomAgent

Shipped

Bids 1–5 uniformly, plays a uniformly random legal card. The baseline.

Source: src/agents/random_agent.ts

The control condition. Every benchmark needs one: if a model can't beat random, you have a problem. Also the fallback when an LLM 429s or errors out, and the engine's last-ditch recovery if it ever has to apply a fallback action mid-loop.

public class RandomAgent implements Agent {
    public RandomAgent(String name);
    // bid:  returns {action:"bid", value: floor(rand()*5)+1, reasoning:"random"}
    // play: picks uniformly from obs.playing_context.legal_plays
}
bid(obs):
    return {action: "bid", value: 1 + floor(Math.random() * 5), reasoning: "random"}

play(obs):
    legal = obs.playing_context.legal_plays
    return {action: "play", card: legal[floor(Math.random() * legal.length)], reasoning: "random"}

HeuristicAgent

Shipped

Rule-of-thumb bidder + card chooser. Fast, deterministic-ish baseline.

Source: src/agents/heuristic_agent.ts

A simple hand-evaluator: counts aces, kings, and long-spade structures for the bid; for plays, follows a fixed priority (try to win cheaply when partner is losing the trick, dump low otherwise). Not strong, but consistent — useful as a sanity check that the engine is feeding sensible observations.

public class HeuristicAgent implements Agent {
    public HeuristicAgent(String name);
    // bid:  derives a value from hand strength heuristics
    // play: picks per a small decision tree over the legal set
}
bid(obs):
    hand = obs.hand.map(parseCard)
    strength = #aces*1.0 + #kings*0.5 + #spades_over_3*0.5 + voidSuitBonus
    return {action: "bid", value: clamp(round(strength), 1, 6), reasoning: "heuristic"}

play(obs):
    legal = obs.playing_context.legal_plays
    if we lead:                       return lowest non-spade if spades unbroken else lowest legal
    if partner is winning current trick:  dump lowest legal
    if we can beat the current winner cheaply: do so with smallest winning card
    else dump lowest legal

OpenRouterAgent

Shipped

Default LLM provider. Multi-model gateway with one-way 429 → Random fallback.

Source: src/agents/openrouter_agent.ts·src/agents/openrouter_agent.test.ts

The default and most-used agent. Hits OpenRouter's OpenAI-compatible chat-completions endpoint. Includes a one-way rate-limit flag: the first 429 trips the flag and every subsequent decision delegates to a private RandomAgent — prevents retry-storming. reset() clears the flag, used when an operator wants to retry the live API.

public class OpenRouterAgent implements Agent {
    public OpenRouterAgent(String name, String apiKey, String? modelId);
    public void reset();                              // clears rate-limited flag
}
private rateLimited = false
private fallback    = new RandomAgent(name)

bid(obs) / play(obs):
    if rateLimited: return fallback.bid|play(obs)
    body = chatCompletionPayload(modelId, buildPrompt(obs), responseFormat="json_object")
    resp = await fetch("https://openrouter.ai/api/v1/chat/completions", body)
    if resp.status == 429:
        rateLimited = true
        return fallback.bid|play(obs)
    json = await resp.json()
    return parseJson(json.choices[0].message.content)

useGame — the main loop

Shipped

initGame, runLoop, humanAction, togglePause, quitGame. Drives the engine + agents to completion.

Source: src/hooks/useGame.ts

Owns the live engine reference and the per-seat agent array. runLoop is the recursive async function that asks the active seat's agent for a bid or play, applies it, advances trick / hand boundaries, and re-schedules itself. When a human takes a seat, the loop pauses on that seat and waits for humanAction to be called from the UI. On game_over, persists the result to localStorage and best-effort to SpacetimeDB.

public interface UseGame {                        // React hook return shape
    GameState?  gameState;
    String[]    logs;                             // last 50 lines
    boolean     isHumanTurn;
    boolean     isPaused;
    void        initGame(GameConfig cfg);
    void        humanAction(BidAction | PlayAction a);
    void        togglePause();
    void        quitGame();
}
initGame(cfg):
    cancel any in-flight loop (bump loopId, drop refs)
    engine  = new GameEngine(cfg.targetScore, cfg.variant, ?, cfg.cheatingPolicy, cfg.rngSeed)
    agents  = cfg.players.map(buildAgent)         // human seats → null
    log("Seed: " + engine.rngSeed)
    isRunning = true
    runLoop(loopId)

runLoop(currentLoopId):
    if cancelled(currentLoopId): return
    if engine.phase == game_over:
        result = saveResult(buildPayload(engine))
        if engine.cheatEvents: log(summary(engine.cheatEvents))
        recordCompleteGame(result, engine.variant, engine.policy, engine.rngSeed)
            .catch(warn)                          // best-effort
        return
    seat  = engine.currentTurn
    agent = agents[seat]
    if agent is null: setIsHumanTurn(true); return
    await sleep(speed)
    obs   = engine.getObservation(seat)
    action = (engine.phase == bidding) ? await agent.bid(obs) : await agent.play(obs)
    err = engine.processBid|Play(seat, action)
    if err: log(err); engine.applyFallback(seat)
    setGameState({...engine.state})
    await sleep(cardDelay)
    if engine.isTrickComplete(): engine.resolveTrick(); emitTrickSummary(); emitRoundSummary()
    runLoop(currentLoopId)                        // re-schedule

useOpenRouterModels — live model catalog

        cached = readCache("openrouter_models", maxAgeMs=24h)

Game table — schema deep dive

Shipped

Per-game row with roster, scores, cheating policy, house rules.

Source: spacetime/module/src/lib.rs

Each finished match is one Game row. Beyond the obvious (scores, models, target), the row carries the full cheating policy in force (allow_renege, chat_policy, prompt_cheating_mode, cheat_consequence_*) and house rules (spades_lead_policy, minimum_team_bid). This means every game in the leaderboard is self-describing — you don't need to look up which rules were active.

table Game {
    u64    id (PK auto);
    u8     schema_version;
    u64?   tournament_id;
    Timestamp started_at;
    Timestamp? completed_at;
    u16    target_score;
    u8     variant;                  // 0=Standard 1=JJA 2=JJDD
    u32    team1_seat0_model_id, team1_seat2_model_id;
    u32    team2_seat1_model_id, team2_seat3_model_id;
    i16    team1_score, team2_score;
    u8     team1_bags,  team2_bags;
    u8     winner_team;              // 1 | 2 | 0 (unfinished)
    u64    rng_seed;                 // splitmix64 seed of the game RNG
    // Cheating policy:
    bool   allow_renege;
    u8     chat_policy;              // 0=None 1=PublicOnly 2=Partner 3=All

    bool   agent_detection_quorum;

// Sample queries you can run from any subscriber:

// Renege rate by model under permissive rules:
SELECT model.name, COUNT(*) AS reneges
FROM decision JOIN game USING (game_id) JOIN model ON model.id = decision.model_id
WHERE decision.engine_cheat_kind = 1 AND game.allow_renege = true
GROUP BY model.name

// Win rate per matchup ignoring forfeits:
SELECT t1m, t2m, SUM(winner=1) AS t1, SUM(winner=2) AS t2
FROM game WHERE cheat_consequence_kind != 2 GROUP BY t1m, t2m

spacetime/encoding — Rust encoding helpers

Shipped

Pure-Rust crate (no external deps) for packing bids/hands/tricks compactly.

Source: spacetime/encoding/

Standalone Rust crate that the module depends on. Provides bit-packers for the fixed-width fields stored on Hand and Decision rows (bids_packed: u32 holds 4 seats × 8 bits; tricks_won_packed: u16 holds 4 × 4 bits; deal_seatN: u64 packs a 13-card hand). Pure Rust, no external dependencies — kept that way to keep the wasm output small.

// pub fn pack_bids(seats: [Bid; 4])      -> u32;
// pub fn unpack_bids(packed: u32)         -> [Bid; 4];
// pub fn pack_tricks_won(won: [u8; 4])    -> u16;
// pub fn unpack_tricks_won(p: u16)        -> [u8; 4];
// pub fn pack_hand(cards: &[CardIndex])   -> u64;   // 13 cards × ~5 bits
// pub fn unpack_hand(p: u64)              -> Vec<CardIndex>;
// pub enum Variant { Standard, Jja, Jjdd }
// impl Variant { pub fn from_u8(u: u8) -> Option<Self>; pub fn to_u8(&self) -> u8; }
// All packers follow the same shape:
fn pack_bids(seats):
    out = 0u32
    for i in 0..4: out |= (encode_bid(seats[i]) as u32) << (i * 8)
    out

fn unpack_bids(packed):
    [decode_bid(((packed >> (i * 8)) & 0xFF) as u8) for i in 0..4]

main():

    page    = await browser.newContext().newPage()
    await page.goto("http://localhost:5273")

    if env.YOUTUBE:

start():
    args = [
        "-f", inputFormat, "-i", inputDeviceOrPipe,
        "-c:v", "libx264", "-preset", "veryfast", "-b:v", "3000k",
        "-c:a", "aac", "-b:a", "128k",
        "-f", "flv", rtmpUrl

winRates(games):
    out = {}
    for each game in games:
        winners = game.winner == 1 ? game.team1Models : game.team2Models
        losers  = game.winner == 1 ? game.team2Models : game.team1Models
        for each m in winners: out[m].wins   += 1
        for each m in losers:  out[m].losses += 1
    annotate each entry with winRate = wins / (wins + losses)
    return out

cheatTally(games, events):
    out = {}
    for each ev in events:
        model = lookupModelForGameSeat(ev.gameId, ev.seat, games)
        out[model][ev.kind] = (out[model][ev.kind] ?? 0) + 1
    return out
